**Dark:** `--bg #100E0A` · `--card #1B1813` · `--sheet #221E18` · `--tx #F3EFE8`

**Акцент-темы УЖЕ реализованы** в коде: enum `AccentColor` (ui/screens/SettingsState.kt) —
MALACHITE/SAPPHIRE/AMETHYST/TERRACOTTA с точными `rgb`. Не дублировать, брать `accentChoice.rgb`.

**Типографика:** заголовки — **Playfair Display** (serif, вариативный, ось `wght`);
текст/подписи — **Manrope** (вариативный). Em-трекинг и веса — как в CSS макета.
⚠️ Вариативные шрифты в Compose: вес применяется ТОЛЬКО через
`Font(resId, weight, variationSettings = FontVariation.Settings(FontVariation.weight(w)))`
+ `@OptIn(androidx.compose.ui.text.ExperimentalTextApi::class)`. Без обоих — ось игнорируется,
заголовки тоньше макета (это уже ловилось — см. KNOWLEDGE §«compile-грабли»).

Все цвета/радиусы/отступы заводить ОДИН раз в `ui/theme/AureliaDesignSystem.kt`
(токены + переиспользуемые компоненты), экраны берут только из темы. Никаких хардкод-hex
в экранах.

**⚠️ Реальная обёртка темы — `AppleAppTheme`** (MainActivity.kt:72), НЕ `AureliaAppTheme`.
Именно `AppleAppTheme` (AppleDesignSystem.kt:163–168) прокидывает `LocalAureliaColors`
с корректной тёмной палитрой (`AureliaDarkColors`) и акцентом (`accentChoice.rgb`).
`AureliaAppTheme` в AureliaDesignSystem.kt — **мёртвый код** (светлое ядро, dark «позже»):
не использовать, удалить при случае. Токены брать через `AureliaTheme.colors`. Отступы кратны 4dp; формы — карточки 16, поля/чипы 8/12, bottom sheet 24,
аватары 50% (сверять с макетом).

## 6. Протокол «пиксель-к-пикселю» (как сверять)

Для каждого экрана сверять по чек-листу и не считать готовым при расхождении:
- [ ] **Цвета** фон/карточка/текст/акцент/разделители = токены Aurelia (light И dark).
- [ ] **Типографика:** семейство (Playfair заголовки / Manrope текст), вес (ось wght реально
      применена), размер, line-height, em-трекинг, цвет — совпадают с CSS макета.
- [ ] **Геометрия:** отступы (кратны 4dp), радиусы карточек/полей/листов, высоты строк,
      размеры аватаров/иконок/тап-целей (≥48dp) — как в макете.
- [ ] **Иерархия и расположение** блоков, выравнивание, порядок — как в макете.
- [ ] **Состояния:** заполнено / пусто (точка входа «+ Добавить…», не «Нет данных») /
      loading (спиннер, не пустой экран) / error / выбран / disabled.
- [ ] **Тёмная тема** не «инвертирована грубо», а по dark-токенам; акценты адаптированы.
- [ ] **Все 4 акцент-темы** не ломают экран (проверить хотя бы emerald + одну другую).
- [ ] Иконки/легенда карты совпадают по цвету со списком (дом/работа/компания/выбранный).

## 8. Среда сборки и гейты (особенности этой машины)

- Java не в PATH: `export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"` перед gradle.
- Сборка: `cd ss-v1 && ./gradlew assembleDebug --no-daemon`.
- QA из корня: `cd /c/ss && PYTHONIOENCODING=utf-8 python qa_check.py` — **зелёный перед
  каждой выдачей и каждым коммитом**.
- Среда офлайн → новые зависимости не качаются. Бинарные ассеты владелец кладёт сам.
- Цикл сборки: первая `e:`-строка важнее десяти догадок → фикс → пересборка.
  `finished` + warning = ОК; паниковать только на `failed` + `e:`.
- qa НЕ ловит: `@Composable` в обычной лямбде; вариативный шрифт без `variationSettings`;
  это всплывает на сборке у владельца — держать в голове (KNOWLEDGE §«compile-грабли»).
