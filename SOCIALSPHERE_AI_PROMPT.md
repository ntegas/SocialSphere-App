# SocialSphere — промт для ИИ: ошибки, которые не должны повторяться

> Вставь этот файл в проект и давай его в начало любого чата по SocialSphere.
> Правило №0: **ни одна ошибка из этого списка не повторяется.** Перед правкой —
> прочитать релевантный раздел; перед выдачей ZIP — прогнать `qa_check.py`.

---

## 0. Рабочий цикл (обязателен на каждый шаг)

1. **Сначала читать реальный код** того, что правишь (не предполагать, что локальная копия = репо).
2. **Искать «мины»** — логику, завязанную на текст русской строки (`when (x) { "Каждый год" -> … }`, `firstOrNull { it == "понедельник" }`). Такую логику переводить на enum/индекс/флаг, НЕ на текст.
3. Правки — атомарным скриптом с `assert` и проверкой баланса `{}` / `()` ПОСЛЕ. Файл писать одним `open(...,"w")` в самом конце блока: если `assert` упал раньше — файл не тронут.
4. **Перед каждым ZIP — `python3 qa_check.py`. Все проверки зелёные.**
5. Собирать всегда ПОСЛЕДНИЙ ZIP в ЧИСТУЮ папку. Перед установкой APK — удалить старое приложение.
6. `&` в строковых ресурсах экранировать СРАЗУ при вставке: `&` → `&amp;` (кроме уже `&amp;|&lt;|&gt;|&quot;|&apos;|&#`).

## 2. Ошибки компиляции (Kotlin / K2 / Compose)

- **Полные пути классов не писать по памяти.** `ChronoUnit` живёт в `java.time.temporal`, не `java.time`.
- **Иконки — каждая требует импорта.** Стандарт: `import ...icons.filled.*`. Точечные импорты икон — мина.
- **Зеркальные иконки на BOM 2024.09.03 — ТОЛЬКО `Icons.AutoMirrored.Filled.X`** (ArrowBack/Forward, Send, List, ExitToApp, Reply…) + импорт `...icons.automirrored.filled.X`. Старый запрет «AutoMirrored нельзя» УСТАРЕЛ. Прочие (не-зеркальные) AutoMirrored по-прежнему нельзя.
- **FlowRow / экспериментальные API:** K2 считает их ошибкой без opt-in. В начало файла ПЕРЕД `package`: `@file:OptIn(androidx.compose.foundation.layout.ExperimentalLayoutApi::class)`.
- **Даты:** только `isBefore()/isAfter()`, НЕ `<`/`>` (K2 спотыкается на операторе).
- **nullable в составном `when`:** K2 не делает smart-cast. Заранее `val du: Long = daysUntil`.
- **`PaddingValues`:** оси (vertical/horizontal) и стороны (top/bottom/start/end) — разные перегрузки, не смешивать.
- **Значения enum НЕ угадывать** — читать `Enums.kt` перед использованием (`CalendarItemType.REMINDER` не существовал).
- **`Объект.функция`:** проверить, что функция реально внутри object, а не top-level (`parseVCard/parseCsv` — top-level).
- **extension-функции** не вызываются по полному пути — нужен импорт (`positionInParent`).

## 3. Ошибки скриптовых правок

- Вставка top-level кода — ТОЛЬКО по уникальному текстовому якорю. `rfind('}')` находит не ту скобку → хелпер вшивается внутрь чужой функции.
- После каждой правки — проверка баланса `{}` и `()`. `return@X: return@X` и подобный мусор = автоправка без проверки.
- В комментариях/строках не писать голые `1)`, `2)` — счётчик скобок врёт. Использовать `1.`, `2.`.

## 4. Импорт контактов (CSV / vCard)

- **CSV-заголовки:** матчинг колонок — сначала ТОЧНОЕ совпадение, потом подстрока С исключениями (title/type/должность НЕ могут быть компанией). `contains("org")` цеплял «Organization 1 - Type/Title» → должности становились компаниями. Юнит-тест на реальных заголовках Google CSV обязателен.
- **vCard:** поля разделены `;`, у строк бывают параметры (`ORG;CHARSET=…:`). Брать `substringAfter(":").substringBefore(";")`. Страж при создании сущностей: `companyName ≠ jobTitle`.

## 5. Runtime / сборка / устройство

- **ClassNotFoundException на компонент манифеста (BootReceiver и т.п.):**
  - Причина A — старый APK / drift: манифест объявляет класс, которого нет в dex. → удалить старое приложение перед установкой; собирать последний ZIP в чистую папку.
  - Причина B (release) — `isMinifyEnabled=true`: R8 вырезает классы, инстанцируемые системой рефлексией по манифесту. → `proguard-rules.pro`: `-keep public class * extends android.content.BroadcastReceiver { *; }` (+ Service/Activity/Application/ContentProvider).
- **`finished` ≠ `failed`:** в логе сборки `finished` + deprecated = ПРЕДУПРЕЖДЕНИЯ, APK собран. Паниковать только на `failed` + `e:`.
- **Сборка падает на ресурсе «does not exist / Access is denied» (напр. `mipmap-xxhdpi/ic_launcher_round.webp`):** это НЕ баг кода — файл в ZIP валиден (страж У53 проверяет целостность всех .webp). Причина — окружение Windows: неполная распаковка (Проводник молча роняет файлы при длинном пути), блокировка антивирусом, или процесс держит файл. Лечение: распаковать через 7-Zip в КОРОТКИЙ путь (`C:\ss\` или `C:\dev\`), `gradlew clean`, `gradlew --no-build-cache assembleDebug`, при необходимости — папку проекта в исключения антивируса.

## 6. Локализация (ru / en / el)

- **Никакой логики на тексте строки.** Тип/статус/режим/повтор/единицы — на enum (`when (enum)`), фильтры — на enum/флаге, табы — на индексе. После перевода лейбла логика обязана работать без изменений.
- **`stringResource` нельзя** в `derivedStateOf` / `remember{}` / lambda / data-слое. Захватывать строки в `val` ДО блока; строки передавать ключами в `remember(...)`, иначе смена языка не пересчитает. В корутинах/`LaunchedEffect` — `context.getString`, не `stringResource`.
- **enum-лейблы — два метода:** `label(context)` через `getString` для UI (Context из `LocalContext.current`, захват в `val ctxLabel` в начале composable — работает во вложенных lambda/map/derived); `labelKey()` со стабильным русским для data-слоя (SearchEngine/ExternalActionHandler — поиск по данным, перевод не нужен). НЕ делать `label()` @Composable — сломает data-слой.
- **Обратный матчинг дропдаунов** `firstOrNull { it.label(ctx) == v }` безопасен ТОЛЬКО если лейблы уникальны внутри enum во всех языках — проверять программно.
- **Роли семьи** (`Жена/Муж/Партнёр/Отец/Мать/Брат/Сестра/Сын/Дочь/Родственник/Друг/Коллега`) НЕ локализуются — это данные в БД (`ContactRelation.role`, матчинг `familyRoles`). Их перевод разорвёт связи. В страже — белый список `ROLE_DATA_OK`.
- **`&` экранировать** в strings.xml сразу. **Дубликаты `<string name>`** ронят AAPT — ловит страж У50.
- Настройки (язык, тема, времена напоминаний) — через `SharedPreferences`/persisted, не `mutableStateOf` (иначе сброс при перезапуске).

## 7. Архитектура (кратко)

MVVM + UDF: данные вниз параметрами, события вверх колбэками. Логика в ViewModel, Composable только рендерит. `viewModelScope.launch` + `withContext(Dispatchers.IO)` для БД/сети. Никаких `!!` — `?.`/`?:`. `derivedStateOf` для вычислений. При смене схемы БД — обязательно `Migration` + version++. Даты — `ISO_LOCAL_DATE_TIME`, не `LocalDate.now().toString()`.

## 8. Стражи `qa_check.py` (зелёные перед каждым ZIP)

- **У41** — вызовы `Объект.функция`, где функция top-level (известный список).
