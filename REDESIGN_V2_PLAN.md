## Как резать секции прототипа (повторяемо)
```bash
cd "Дизайн Android приложения (2)" && awk -v out="ПАПКА" '
BEGIN{n=0; fn=out"/00_preamble.html"}
{ if (match($0, /<!-- =+ [A-ZА-Я \/]+ =+ -->/)) { name=substr($0,RSTART,RLENGTH);
  gsub(/<!-- =+ /,"",name); gsub(/ =+ -->/,"",name); gsub(/[ \/]+/,"_",name);
  n++; fn=sprintf("%s/%02d_%s.html",out,n,name) } print >> fn }' "Socialsphere Прототип.dc.html"
```
